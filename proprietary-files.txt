# Face -- DELIBERATELY NOT EXTRACTED.
#
# Sony's android.hardware.biometrics.face@1.0-service.face crash-loops forever:
#   Face HAL started
#   Check failed: status == STATUS_OK       -> SIGABRT
#   servicemanager: Could not find android.hardware.biometrics.face.IFace/default
#                   in the VINTF manifest. No alternative instances declared.
#
# Declaring the interface would not help. The Android 16 framework matrix
# requires android.hardware.biometrics.face AIDL version 3-4, and this binary
# links android.hardware.biometrics.face-V1-ndk (confirmed in
# vendor/sony/pdx246/Android.bp) i.e. AIDL V1; and NOTHING would consume it anyway, because neither we nor
# stock declare the android.hardware.biometrics.face FEATURE, so FaceService
# never looks for it. Stock ships and enables this service without declaring
# the interface either, so it presumably crash-loops there too.
#
# Shipping it only burns CPU and floods the log with a restart every 5 s.
# To restore (e.g. if face unlock is ever attempted), re-add both lines AND
# declare the AIDL interface at a version the framework matrix accepts:
#   vendor/bin/hw/android.hardware.biometrics.face@1.0-service.face
#   vendor/etc/init/android.hardware.biometrics.face@1.0-service.face.rc
